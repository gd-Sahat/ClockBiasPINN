# Clock Bias Transformer 🚧 Under Development

> Predicting GNSS clock‐bias differences using a Transformer model.

## 📖 Overview
This repository contains an experimental implementation of a Transformer-based neural network to predict clock‐bias differences (`bias_diff_ns`) from GNSS satellite data. It’s a work in progress—expect frequent changes and incomplete features.

## 🔧 Status
**⚠️ Project is under active development. Not production-ready. ⚠️**  
- Core data preprocessing & temporal splitting: ✔️  
- Transformer architecture & training loops: ✔️  
- Evaluation, logging & checkpointing: 🔄 In progress  
- Documentation & examples: 🔄 In progress
